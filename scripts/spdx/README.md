# Canonical licence texts

The texts `scripts/third-party-notices` attaches to a crate that ships no licence file of its
own, one per SPDX licence id its expression names. Each file is `text/<id>.txt` of the SPDX
License List 3.29.0 (<https://github.com/spdx/license-list-data/tree/v3.29.0/text>),
unmodified. The set holds the licences such crates declare; a crate whose licence has no text
here stops the notices run, which names the id to add.
